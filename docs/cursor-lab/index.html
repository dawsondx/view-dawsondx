WHY NOT NATIVE

原生指针没有状态语义。自定义指针能把「这里能点 / 这里能输」提前 120ms 告诉用户，比 hover 变色更早。

COST

一次 rAF + 一个 translate3d，无布局读取。只在 pointer:fine 设备启用，触屏与 prefers-reduced-motion 自动退回原生。

INVERSE

elementFromPoint 向上找第一个非透明底色，算亮度：低于 0.45 自动切反白，不依赖手写 section 标记。
