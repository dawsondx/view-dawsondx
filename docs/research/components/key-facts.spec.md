# KeyFacts Specification

## Overview
- Target: `src/components/KeyFacts.tsx`
- Interaction: entry reveal + media

## Styles
- Background `linear-gradient(#d2d2d2 0%, #fff 100%)`, dark copy `#434343`.
- Desktop title around `76px / 72px`; subtitle 12.8px.
- Grid cards use 1px translucent borders and 4–8px radius.
- Counters use PP Editorial; award/team labels use Familjen.

## Content
- Heading: `Key facts`
- Subtitle: `A snapshot of our experience and impact.`
- 50+ projects, 14+ years, 20+ team members, 90% returning clients.
- Award logos and partner logos use local `/images/*.svg`.
- Awards video: `/video/awards-card-video.mp4`; team video: `/video/team/rushi.mp4`.

## Responsive
- Desktop: asymmetric 12-column cards.
- Tablet: two columns.
- Mobile: single column and mobile video variants.
