# Trionn Homepage Page Topology

## Observed document

- Desktop document height: `25,056px` at `1440 × 900` during the first capture.
- Default controlled viewport document height: `20,249px` at about `1265px` content width.
- Main is `position: relative`, `overflow-x: clip`.
- Header is fixed above all scenes.

## Visual order

1. **Header** — fixed logo, sound toggle, `LET'S TALK`, menu pill.
2. **Hero** — one viewport, deep black, time-driven headline word, interactive extruded symbol, wire lines, start-project CTA, facts block and hold-to-blast hint.
3. **About** — one viewport, dark; giant low-opacity statement becomes legible as the scroll passes it.
4. **Vision** — one viewport, dark pinned text: `INSPIRE / INNOVATE / IMPACT`; shares the hero symbol lifecycle.
5. **Key Facts** — light gradient, awards, counters, team/video card and partner logo rail.
6. **Selected Work** — pinned horizontal gallery; intro card, MyWorker AI, Pulse Studio, Loftloom and final all-projects card.
7. **Services / Stone Sequence** — black full-screen pinned sequence; original loads 371 stone WebP frames and blends a services video. Clone uses a lighter code-driven transition and local video.
8. **Client Stories** — light gradient; click-driven testimonial selector with five states.
9. **Creative Orbit** — long pinned experiment/orbit area with scroll-driven cards and large opposing marquees.
10. **Footer / Contact** — dark, full-screen canvas energy field, large CTA, enquiry and social links.
11. **Cookie Banner** — fixed bottom overlay until declined or accepted.

## Dependencies

- Hero, About and Vision share the same dark scene and scroll progress.
- Work gallery and Services are consecutive pinned narratives.
- Header changes contrast over light sections; the clone uses blend mode plus an explicit scrolled state.
- All interactive scenes pause or simplify for `prefers-reduced-motion`.
